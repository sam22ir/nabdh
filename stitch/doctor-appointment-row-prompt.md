# Stitch Prompt: Doctor Appointment Row Redesign

Create a mobile screen for the Nabdh doctor role, Arabic RTL, focused on the appointments page at 593px wide.

Use the attached Nabdh design system. The screen should include:
- Deep clinic navy header with the title "مواعيد العيادة".
- Search bar below the header with placeholder "ابحث باسم المريض أو رقم الهاتف" and a filter button.
- Period segmented control with "اليوم" active, plus "الأسبوع" and "الشهر".
- Section title "قائمة المواعيد" with subtitle "استخدمها للفرز، المتابعة، وإضافة ملاحظات الطبيب".
- Inline count text "11 موعداً اليوم", highlighted by blue text only, not a pill or button.
- A redesigned appointment row for a no-show appointment:
  - Patient name: "سمير".
  - Status: "لم يحضر".
  - Time: "09:00".
  - Visit details: "زيارة أولى · بدون سبب مسجل".

Redesign requirements for the appointment row:
- Remove all person/user symbols and decorative icons from the row.
- Make the row readable at a glance: patient name and status on the top line, time and visit details on the second line.
- Use a white card with a quiet border and 8-10px radius.
- Status chip should use a soft danger background and danger text.
- Time should be blue, bold, and easy to scan.
- Metadata should be muted, right aligned, and able to wrap without overlap.
- Do not make the row look selected, highlighted, or like a blue button.
- Keep the bottom tab bar visible with five tabs: "لوحتي", "المواعيد", "الجدول", "ملفي", "الإعدادات".

Do not add emojis. Do not use decorative medical illustrations. Keep the screen operational, calm, and official.
